# Phase 10 Desktop Workspace and Preview Workflow

**Status** Phase 10 is complete for the local Windows 11 x64 handoff in beta 31. Beta 28 remains the comparison baseline. [10A results](phase-10a-baseline.md) · [10H verification](#10h-local-windows-results) · [Windows build record](windows-release.md#verification-status)

## Purpose and starting point

At 1920 × 1080, use a vertical navigation menu on the left with **Panels** and **Preview**. Each opens a dedicated view that uses the workspace to the right of the menu. Share job status and the Command Panel across both views so users can follow work while switching between them.

Beta 28 opens maximized, puts panels beside the preview when the controls fit, and stacks them in narrow windows. The divider remembers separate positions for each orientation during the session. The desktop already supports keyboard pan, zoom, fit and crop, per-panel solve details, and project undo and redo. Use these interactions as the baseline for the new controls. [Desktop workflow](guide.md#run-the-desktop-app) · [Phase 9 history](phase-9.md)

Design for a rectangular desktop display at normal desk distance using the existing PySide6 Widgets themes, mouse and keyboard. Keep the preview and the next workflow action prominent. Place contextual details close to their controls. Use English default labels and retain locale-aware numeric entry.

## Workspace layout

~~~text
┌──────────────────────────────────────────────────┐
│ Application menu bar                             │
├───────────┬──────────────────────────────────────┤
│ Panels    │ Active view                          │
│ Preview   │ Panel table or mosaic preview        │
├───────────┴──────────────────────────────────────┤
│ Shared job status and Command Panel              │
└──────────────────────────────────────────────────┘
~~~

| View | Controls and content |
| --- | --- |
| **Panels** | Add and inspect panels, review WCS status, run Plate Solve and edit panel settings. The table fills the available content area and scrolls within the view. |
| **Preview** | Build and inspect the mosaic, choose the layer and band, adjust framing and crop, and export. When inputs are needed, offer a direct way back to **Panels**. |

Keep the left menu in both layouts. On compact windows, use a slimmer menu with keyboard-accessible labels and adapt the view controls with wrapping or an overflow menu. **Panels** is the starting view for an untitled workspace. Selecting a menu item changes the main view within the active project.
